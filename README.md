## 🚀 Що додано в цьому оновленні

1. **🔄 Повноцінний блок редизайну сайту («До» та «Після»):**
   * **До мого приходу:** Додано реальний скріншот початкового сайту з мильними бульбашками та QR-кодами, розбір помилок UX (візуальний шум, перевантаженість, відсутність сітки).
   * **Після редизайну (моя робота):** Презентація поточної темної дизайн-системи, ітерацій UI-іконок та пряме посилання на діючий маркетплейс `why-not.com.ua`.
2. **👕 Розширена колекція авторського мерчу:**
   * 3D-колода презентації дропу футболок (`DROP TRIO`).
   * Футболка Acid-Wash (чорна): *«Мрії можуть підняти, але не забувай про межі»* з фіолетовим ланцюгом.
   * Футболка оверсайз (біла): *«Мрії можуть підняти...»* (White Edition).
   * Футболка Vintage Serif: *«Плями — доказ що ти жив, а не боявся»*.
   * Футболка *«Скутий Ангел»* у стилі кіберпанк.
   * Футболка *«Кібер-Лікоріс»* із японським канджі 死.
   * Еко-шопери: *«Кібер-Ангел»* та *«Кібер-Лікоріс»*.
   * Керамічна кружка *«СТРАХИ»* у полум'ї.
   * **Інтерактивна фільтрація:** кнопки перемикання *«Всі товари»*, *«Футболки»*, *«Шопери & Посуд»*, *«Дроп-колода»*.
3. **🦝 Інтерактивний курсор та спливаючі фрази:**
   * Курсор у вигляді круглого логотипу-єнота з реакцією на клік і ховер.
   * Інтерактивні репліки при кліку на екран трьома мовами.
4. **🌐 Повна тримовність:** Українська, English, Русский.
